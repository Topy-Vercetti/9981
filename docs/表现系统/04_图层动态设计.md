# 图层动态设计（当前层工作区与跨层拓扑）

> **归属**：表现系统 · 图层子系统  
> **状态**：现行设计（2026-09-05）  
> **替代**：废弃 `height`、相邻层透明度、建筑组与建筑作用域模型。

## 一句话定位

图层是彼此隔离的编辑与表现工作区；跨层关系由普通拓扑边表达，不由视觉高度推导。

## 1. 图层契约

`MapLayer` 只描述稳定 id、名称、可选底图与图像变换。它不包含 `height`、`opacity` 或建筑组引用。

场景节点、地形和障碍必须带 `layerId`。放置物通过宿主场景继承图层归属，边通过两端场景推导同层或跨层关系。

旧数据中的图层 `height` 和顶层 `buildingGroups` 在导入规范化时被忽略并剥离；再次序列化时不得出现这些字段。

## 2. 当前层独占工作区

编辑器只渲染、命中和编辑 `currentLayerId` 的底图、场景、放置物、地形、障碍与同层边。切换图层保留相机位置，但清理不属于目标层的普通选择和待定图像缩放状态。

空白左键拖拽平移画布；按住 Control（macOS 同时支持 Command）拖拽才框选。框选、聚合、命中、删除和诊断都必须限制在当前图层。

删除图层会级联删除该层场景、场景框、放置物、地形、障碍，以及所有连接被删场景的边。若删除最后一个图层，编辑器创建新的默认空层。

## 3. 跨层拓扑

跨层连接仍使用普通 `Edge`。楼梯、电梯、窗户和传送门等行为由 `edge.def` 与方向性表达，不新增传送专用边，也不把接力状态写入地图 JSON。

E 拉边从当前层场景开始。若在另一图层行释放，编辑器保存一次性的接力草稿并切换到目标层；点击目标场景后创建普通边。来源场景删除、来源或目标图层删除、切换工具、Esc 或显式取消都会清除草稿。

同层边绘制完整样条。跨层边不绘制跨画布长线，而在两端场景旁显示门户端点徽章：

- 徽章显示边的方向。
- 点击或键盘激活徽章会选中原始边、切换到另一端图层并聚焦目标场景。
- 删除选中的门户端点等价于删除原始边。

## 4. 对局表现边界

表现投影透传图层底图、变换和比例尺，不再输出 `LayerView.height`、`LayerView.opacity`、建筑渲染模式或建筑作用域状态。规则状态和寻路仍只依赖拓扑；图层切换不修改规则事实。

UI、全屏特效等常驻界面属于独立的界面层级，不通过地图图层 `height = null` 表达。

## 5. 验收约束

- canonical 序列化结果不含 `height` 或 `buildingGroups`。
- 当前层之外的普通图元不可见、不可命中、不可框选。
- 地形和障碍不会跨层聚合或误删。
- 跨层接力可完成、取消，并在删除来源时安全失效。
- 两端门户徽章均可导航到另一端并编辑同一条原始边。
